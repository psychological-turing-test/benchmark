# 有限理性图灵测试教程的写作提纲

## 标题与定位

中文标题：像人一样决策：大语言模型的有限理性图灵测试

英文标题：Judging like humans: A tutorial on the bounded rationality Turing test
for LLMs using classic social psychology paradigms

本文介绍“类人决策评测工具”，整合已有社会心理学任务、人类参考分布与行为度量，
帮助研究者简易、公平、可复现地比较模型与人类决策偏好的异同。国产模型
实验是工具的应用示例，用于讲解结果并提出初步发现。测量限制和敏感性分析
服务于这一教程主线。

研究动机来自判断任务的人力替代需求：在常规判断之外，模型面对利弊权衡
是否选择得像人，其后续版本又会趋近还是偏离人的有限理性？当前示例回答
部分配置比较问题；跨版本趋势是工具支持的后续研究，不是现有数据的结论。

有限理性是理论视角，图灵测试是行为比较思路；不将选择相似等同于机制相同。
公平指评测程序可比；复现包括材料与流程可检查、已保存结果可离线复算，
不承诺随机输出逐次相同。BAS、VAS及SRS是工具中的汇总规则，不能称为
原始研究已经验证的心理量表分数。

## 全文结构

1. 引言：从替代机械性判断、节约人力成本，引出涉及利弊权衡时能否像人
   一样选择的问题；先问决策偏好是否一致，再问模型迭代中趋近还是偏离人的
   有限理性。继而介绍理论、范式与工具，简述国产模型结果及复核证据。
   采用连续段落，不设小标题，篇幅约2,800字。用生产率研究支持应用动因，
   用行为图灵测试研究衔接相关工作；当前配置比较不推断发展趋势。
2. 比较框架：区分类人偏好与规范标准，解释单题选择分布和条件效应，
   明确横截面配置比较与版本变化的研究要求。
3. 工具与评分：介绍组件、程序公平、题项与人类参照、施测记录、评分公式
   和行为指标。明确材料来源尚待核实的环节。
4. 使用教程：准备材料，选择模型与运行设置，执行问卷，核查输出，评分并
   解读图表。提供最小命令、无需新模型调用的离线学习路径，并说明如何
   保持条件一致、分别保存批次，组织后续版本比较。
5. 国产模型示例：说明19个配置及数据范围，展示任务依赖性、框架与决策
   前提响应、配置差异；用两模型跨任务次序变化说明总分局限，并用常量
   基线和敏感性分析辅助判断。报告原始计数与独立复算的一致性。
6. 讨论：回应效率与偏好的不同要求，解释示例的任务依赖性，提出检验
   趋近或偏离的纵向设计；随后讨论材料、评分、人类参照和运行记录限制。
7. 结论：区分当前比较的初步发现与仍待验证的跨版本变化。

## 内容核对要求

- 数值、图表与已有审校结果保持一致，不新增未经验证的效果或因果结论。
- 区分作答者自身年龄与救助对象年龄；程序题不直接解释为公平随机化测量。
- 近零的有向平均差分应检查抵消，不能直接判定不存在条件响应。
- 国产模型指DeepSeek、GLM与Qwen示例，不外推为全部国产模型的总体结论。
- 题项出处、授权、伦理和历史参数缺项继续保留待补，避免以教程定位略去。
